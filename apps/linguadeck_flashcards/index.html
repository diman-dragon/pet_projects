    Добавить карточки

    Одна строка — одна карточка: слово ; перевод ; транскрипция ; пример 1, пример 2

    Подробнее о формате
    • Обязательны первые два поля, остальные можно оставлять пустыми: слово;перевод;;пример
    • Если в тексте есть ; — возьмите поле в "кавычки": "нарочитый; обдуманный"
    • Запятая внутри примера — \,. Лишние поля после четвёртого тоже считаются примерами
    • Разделитель определяется сам (;, Tab или |) — или выберите вручную

    Синхронизация с Google Drive

    Локальная SQL-база и OPFS остаются основными. В Google Drive приложение создаёт папку «Flashcards»: manifest.json, данные синхронизации и отдельные медиафайлы по SHA-256. Изменения объединяются между устройствами. Для первого подключения нужен OAuth Client ID вашего Google Cloud проекта.

    Импорт колод

    Файл экспорта (.json) — одна колода или полный бэкап. Импорт всегда создаёт НОВЫЕ колоды, существующие не трогает.
