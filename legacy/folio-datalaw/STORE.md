# Публикация в Google Play — чек-лист (проверено 14.10.2026)

## Технические требования
- [x] **Target API 36** — обязателен для новых приложений и обновлений с 31.08.2026 (`android/variables.gradle`: `targetSdkVersion = 36`). Старые приложения должны быть не ниже 35.
- [x] Публикация в формате **AAB** (`folio-datalaw_<версия>.aab` из CI, нужны секреты подписи). Включайте **Play App Signing**; ваш ключ — это upload key.
- [x] `versionCode` растёт с каждой загрузкой: `мажор*1 000 000 + минор*1 000 + патч` (0.0.1 → 1, 0.1.0 → 1000).
- [x] Нет «опасных» разрешений: только `INTERNET` (по умолчанию в шаблоне Capacitor, Folio сеть не использует). Доступ к файлам — через системный выбор файла, `MANAGE_EXTERNAL_STORAGE` не нужен.
- [ ] Проверить на устройстве Android 16: edge-to-edge (SystemBars, `insetsHandling: css`) и системная кнопка/жест «Назад» (App plugin).
- [ ] 16 KB page size: собственного нативного кода нет, но проверьте отчёт Pre-launch в Play Console после первой загрузки.

## Аккаунт
- Новый **личный** аккаунт (создан после 13.11.2023): сначала **закрытое тестирование — минимум 12 тестировщиков, подписанных непрерывно 14 дней**, затем заявка на доступ к production. Аккаунт организации от этого освобождён. Закладывайте ~3 недели до первого релиза.
- Internal testing (до 100 человек, без проверки) — для быстрых итераций, но в 14 дней не засчитывается.
