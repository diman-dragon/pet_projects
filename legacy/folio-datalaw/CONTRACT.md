# Контракт

1. **Атомарность, без фанатизма.** 1 файл = 1 ответственность. 1 изменение = 1 цель.
   Первая строка каждого `.js`/`.css` файла (`// ...` / `/* ... */`) — одна фраза о его ответственности.
2. **После каждого изменения** — `npm run check`. Нарушение атомарности чиним сразу, до следующего шага.
   Проверки (`scripts/checks/`): размер файлов, заголовок-ответственность, резолв импортов, паритет ru/en, согласованность версий.
3. **Версия.** Каждое изменение поднимает последнюю цифру: `npm run bump` (0.0.1 → 0.0.2).
   `0.1.0` — только по команде владельца. После бампа — запись в начале `CHANGELOG.md`.
4. **Имена сборок:** `folio-datalaw_<версия>_debug.apk` (debug), `folio-datalaw_<версия>.apk` и `.aab` (release).
5. **Форматы — модули.** Новый формат = папка `www/js/formats/<fmt>/` + одна строка в `formats/index.js`. Ядро о форматах не знает.
6. **Только PDF** в 0.0.x. Остальные форматы — потом, отдельными модулями.
