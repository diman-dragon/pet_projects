# Google Play — раздел «Безопасность данных» (Data safety)

Заполняйте по факту; ниже — ответы для текущей версии приложения. Перед отправкой сверьтесь с актуальной страницей
Google «ML Kit → Android data disclosure», т. к. ML Kit — единственная библиотека, которая что-то отправляет в сеть.

## Общие ответы
| Вопрос | Ответ |
|---|---|
| Собирает ли приложение пользовательские данные? | **Да** — только технические данные SDK Google ML Kit (диагностика) |
| Передаёт ли данные третьим лицам? | Нет (ML Kit по своему раскрытию не передаёт собранное третьим лицам) |
| Шифруется ли передача? | Да (HTTPS) |
| Можно ли удалить данные по запросу? | Данных пользователя нет; фото/видео лежат только на устройстве |
| Есть ли аккаунты? | Нет |
| Реклама / покупки | Нет |

## Типы данных, которые отметить (за ML Kit)
| Категория Play | Отметить | Цель | Обязательно? |
|---|---|---|---|
| App info and performance → Diagnostics / Crash logs | да | Analytics, App functionality | да (нельзя отключить) |
| Device or other IDs | да (идентификатор экземпляра SDK) | Analytics | да |

## НЕ собирается (оставить пустым)
Фото и видео, аудио, точное/примерное местоположение, контакты, сообщения, персональная информация, финансовые данные, история поиска/просмотров.
Снимки и аудио обрабатываются только на устройстве и никуда не отправляются.

## Разрешения и обоснование (для ревью)
- `CAMERA` — основная функция: съёмка фото/видео.
- `RECORD_AUDIO` — запись звука в видеороликах.
- `VIBRATE` — тактильный отклик затвора.
- `INTERNET` (подключается Capacitor/ML Kit) — не используется приложением для передачи медиа.

## Анкета возрастного рейтинга (IARC)
Приложение-камера: насилия, азартных игр, UGC-обмена и покупок нет → ожидаемый рейтинг «Для всех».
