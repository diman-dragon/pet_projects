# ShchelkovoTaxCourt

Internal documentation and data repository on lawsuits filed by the Interdistrict Federal Tax Inspectorate (MIFNS) in the Shchelkovo City Court.

## Purpose

This repository is intended for structured documentation of court cases, including claim materials, procedural documents, and case progress tracking.

## Structure

* **/cases** – case summaries and procedural histories
* **/documents** – scanned or digitized materials (claims, rulings, decisions)
* **/analysis** – internal notes and legal assessments
* **/archive** – closed or archived cases

## Usage

The repository serves as an internal reference and documentation system.
Access is restricted; materials may contain confidential information.

## Format Guidelines

* Each case folder: `YYYY_NNNN_[short title]`
* Summary file: `summary.md`
* Attachments: in `/documents` with clear naming (e.g. `decision_2024-05-12.pdf`)
* Notes and analysis in `/analysis`
