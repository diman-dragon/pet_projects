# MediaOrganizer

Сортировщик и дедупликатор медиафайлов с графическим интерфейсом.

## Что делает

1. Рекурсивно обходит папку-источник
2. Классифицирует каждый файл:
   - **Видео** → папка `Видео/`  (mp4, mov, avi, mkv, wmv, m4v, mts, ...)
   - **Фото** → папка `Фото/`   (jpg/jpeg/png/tiff с EXIF + RAW/HEIC)
   - **Картинки** → папка `Картинки/`  (те же форматы, но без EXIF)
   - **Гифки** → папка `Гифки/`  (gif, apng)
3. Проверяет каждый файл на дубликат в папке назначения (по MD5-хешу)
   - Дубликат найден → файл **удаляется** из источника
4. Переименовывает по стандарту `YYMMDD_NN.ext`
   - `YYMMDD` — дата из метаданных медиа (EXIF для фото, hachoir для видео),
     при отсутствии — дата из файловой системы
   - `NN` — порядковый номер внутри одного дня (01, 02, ...)
5. Перемещает файл в нужную подпапку назначения
6. Ведёт лог-файл `media_organizer.log` в папке назначения

## Установка

```bash
# Python 3.9+
pip install -r requirements.txt
```

Для поддержки HEIC (iPhone):
```bash
pip install pillow-heif
```

## Запуск

```bash
python main.py
```

## Структура папки назначения

```
Назначение/
├── Видео/
│   ├── 230615_01.mp4
│   ├── 230615_02.mov
│   └── ...
├── Фото/
│   ├── 230615_01.jpg
│   └── ...
├── Картинки/
│   └── ...
├── Гифки/
│   └── ...
└── media_organizer.log
```

## Примечания

- Если Pillow не установлен: JPEG/PNG без проверки EXIF → все попадут в `Картинки/`
- Если hachoir не установлен: дата видео берётся из файловой системы (менее точно)
- Файлы внутри папки назначения в процессе обработки пропускаются автоматически
- Безопасно запускать повторно: дубликаты уже перемещённых файлов будут удалены

## Поддерживаемые форматы

| Категория  | Расширения                                                  |
|------------|-------------------------------------------------------------|
| Видео      | mp4 mov avi mkv wmv m4v 3gp flv webm mts m2ts ts vob mpg mpeg divx rmvb asf ogv |
| Фото (always) | heic heif raw cr2 cr3 nef arw dng orf rw2 pef srw x3f 3fr raf |
| Фото/Картинки | jpg jpeg tiff tif png bmp webp (зависит от наличия EXIF) |
| Картинки   | png bmp webp ico psd ai eps svg xcf                        |
| Гифки      | gif apng                                                    |
